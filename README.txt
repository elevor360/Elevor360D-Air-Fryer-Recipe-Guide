Elevor360D Air Fryer Recipe Guide V1
50 individually drafted recipes with suggested air fryer temperatures and cooking times.
Includes large graphic timers, favourites, shopping list, meal planner, personal recipes,
backup and restore, offline PWA installation and rotating adverts.

GITHUB PAGES: Upload all website files and the advertising folder to the repository root.
KEEP Elevor360D_Air_Fryer_Recipe_Manager_V1.html on your computer, not on GitHub.
Use the manager to import recipes.json, add/edit/delete recipes, export updated
recipes.json, and replace it in GitHub. The service worker caches built-in recipes;
after changing recipes.json increment the CACHE name in sw.js to prompt an update.

ADVERTS: Compatible with the existing advertising/adverts.json and images folder.
Sunset Banner.png is included.

FOOD SAFETY: Times vary by air fryer. Follow appliance instructions, use a food
thermometer for chicken and sausages, and check fish is cooked through.
These 50 recipes are editorial drafts and have not been kitchen-tested.
